\begin{flushleft}
	Real-time object detection plays a fundamental role in the advancement of autonomous and security systems. The integration of this technology with multi-axis gimbals not only provides image stabilization and precise tracking but also significantly expands the operational field of view. In the aeronautical context, this integration manifests in optoelectronic sensors crucial for military and reconnaissance operations. However, a persistent challenge lies in maintaining reliable tracking, given the intrinsic balance between detection algorithm precision and computational cost, as well as the complex dynamics of the gimbal (including nonlinearities and communication delays).
	This master's project aims to develop a robust control solution for real-time object tracking in acquired images. To this end, YOLOv8, a state-of-the-art object detection algorithm, is employed, whose output feeds a PID control system. The control actuation is performed on a two-degree-of-freedom gimbal, responsible for adjusting the camera's orientation to keep the object centered. The performance validation of the proposed control techniques is carried out in a simulation environment (Simulink), executed in real-time, allowing for a comprehensive evaluation under conditions that emulate operational scenarios.
\end{flushleft}
