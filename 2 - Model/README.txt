% Instructions for running the model

1 - Run script "MestradoLucasAvila\2 - Model\scripts\00. Python\Object_detection.py";
2 - Load parameters "MestradoLucasAvila\2 - Model\parameters\Gimbal_Parameters.m";
3 - Download and install OBS Studio software - https://obsproject.com/pt-br/download;
4 - Run the model "MestradoLucasAvila\2 - Model\models\Gimbal_Model.slx", using DESKTOP REAL-TIME app in SIMULINK.
5 - Configure OBS Studio's virtual camera and link to the "Camera Display" window, which outputs after running Gimbal_Model.slx - https://obsproject.com/kb/virtual-camera-guide;
